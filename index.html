Rendered preview Open the raw signature for copying

Gmail

  1. Open the raw signature.
  2. Select all, then copy.
  3. Paste into Gmail Settings, General, Signature.

Gmail re-hosts the pasted images on its own CDN.

Apple Mail

  1. Quit Mail completely.
  2. Run python3 install-apple-mail.py
  3. Start Mail, check a new compose window.

Pasting does not work in Mail, and the installer needs Full Disk Access. See the README for the iCloud and line-ending traps.

Updating

  1. Edit damian-sova-signature.html.
  2. Commit and push. Pages redeploys within a minute.
  3. Reinstall into each mail client, since every client keeps its own copy.

Images are referenced by absolute URL, so replacing a file in assets/ takes effect everywhere on push, with no reinstall.
